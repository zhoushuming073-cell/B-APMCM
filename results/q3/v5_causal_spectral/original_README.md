# Q3 V5 causal spectral prediction
Both variants use H0 (0.5 s per row), ten outer heat folds, nine inner heat folds per outer fold, raw gas labels at detector times >=120 s. 22,378 target observations per family across gases. Five families (prior, process, spectral, fusion, feedback60) independently selected by inner macro R2. All training uses historical heats only except feedback60, which accesses only detector observations already available at publishing time and holds the residual until the next scheduled observation. Feedback begins after the first scored detector observation (120 s). No future test spectral or oxygen values in predictors. The spectral-lag variant selects a fixed lead on training spectral brightness and gas differences. q2_fixed adapts the Q2 fixed-shift model to backward flow averages and selects the lead by training-only LOHO MAE; this is not a full reuse of Q2 continuous curves or its flow-varying delay law. Spectral features use prior physical-band caches and trailing smoothers, not the exact Q1 continuous reconstruction. Pure spectral predictors omit process/time covariates but delay calibration is common across families. Prior SIM/FPCR are revised regularized versions, not exact V4. Fusion candidates include pooled direct ridge/PLS, equal-average heat ridge experts and cross-fitted residual corrections of median/SIM/FPCR templates. All models exploratory; prior model-family discovery used these same ten heats. No GitHub submission.
Run from extracted directory: python run.py --cache q3_eda --out rerun; python q2_fixed/run.py --cache q3_eda --out rerun_q2_fixed. Requires numpy pandas scipy scikit-learn threadpoolctl. Exact prior cache bundled. summary.csv reports macro and pooled R2, macro RMSE and lead ranges. feedback_sensitivity.csv uses the selected spectral-lag fusion model and fixed gains at different sampling intervals (not selected by test results). 223780 prediction records and 200 outer scores independently recomputed.

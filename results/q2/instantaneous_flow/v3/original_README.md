# Q2.2 V3 dynamic heterogeneity
Run `python run.py --input process.csv --out rerun`. Exact V2 process data, 10 heats and 13,589 observations; H0 official 0.5 s, H1 hypothetical fifth heat 1 s. Zero lag and raw labels at row index >=120, identical to V1/V2. Common curve on 10 m3 net oxygen grid, Gaussian smoothing sigma 60 m3, support masks, endpoint fallback. Test descriptors use only current/past oxygen (10/30/60/120 s trailing rates, average rate, changes, elapsed time) or fixed first 121 rows. Training grid interpolation and symmetric smoothing only on historical heats. Dynamic local similarity weights, stage-varying ridge coefficients (100/300 m3 smoothing), and local projected factor loadings (1/2 PCA factors; 200/500 m3 windows) with strong ridge shrinkage; 55 candidates per fold. Nested LOHO selects each family and overall candidate by inner macro R2. Test labels only used for scoring. H1 shared 0.659590/0.845722; no dynamic family beats shared macro R2 for either gas. H0 also no improvement. All 10 heats previously explored, no external confirmation. No Q2.1 reconstruction or Q2.3 lag, no GitHub commit. The adapted dynamic factor model is not an exact replication of a published finance estimator.

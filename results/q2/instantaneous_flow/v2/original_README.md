# Q2.2 V2 heterogeneous curves
Run `python run.py --input process.csv --out rerun`. Input is copied unchanged from Q2.2 V1 local process CSV (13,589 rows, ten heats). All scored observations are raw gas at row index >=120, matching V1; no lag or Q2.1 reconstruction. H0 0.5 s throughout, H1 fifth heat 1 s (unverified). Oxygen coordinate is monotone net cumulative oxygen. Historical curves interpolated on fixed 0–4000 m³ grid, 10 m³ spacing, Gaussian smoothing sigma 60 m³. Shared curve averages training heats with support masks (fallback endpoint extrapolation); other variants use low-rank PCA score regression, K-means response clusters with oxygen-only soft gating, oxygen-characteristic kernel weights, and bounded shape-invariant regression with ridge-predicted parameters. Prefix uses first 121 rows (available by first scored row); full uses complete oxygen trajectory and is OFFLINE explanatory, not online predictive. Inner leave-one-heat mean R² selects parameters per family; test gas never used for model selection. 59 candidates per fold, 40 outer gas/timebase folds. Oracle aligns shared training curve to test gas using test labels: diagnostic only, not predictive or a formal upper bound. V1 comparator scores are separate prior run on the same row indices. All ten heats previously explored; not external validation. No robust improvement over simple shared curve or V1 for CO. Endpoints of historical curves are extrapolated in some latent factor / group fits; model results exploratory. No GitHub commit.

Literature: Pesaran, Shin & Smith (1999), DOI 10.1080/01621459.1999.10474156; Kelly, Pruitt & Su (2019), JFE 134(3), 501–524; Bonhomme & Manresa (2015), DOI 10.3982/ECTA11319; Lindstrom (1995), DOI 10.1002/sim.4780141807; Dynamic Modeling and Simulation of Basic Oxygen Furnace (BOF) Operation (2020), DOI 10.3390/pr8040483. Adaptations are inspired by these methods, not exact replications.

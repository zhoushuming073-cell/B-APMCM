## 方法学诊断

1. 当前按最大绝对相关系数选峰，会混合正、负相关峰。H0、90 s Pearson 中，CO 有 25/71 个窗口选中负峰，CO₂ 有 42/71 个窗口选中负峰。负峰不能直接解释为同一种正向响应时滞。
2. H0/H1 的 90 s Pearson 窗口经循环移位检验和 BH 校正后，CO、CO₂ 均无窗口达到 q≤0.1。但每个窗口仅有 13 个有效零样本，最小可达 p 值为 1/14≈0.0714；不能把未通过校正直接解释为不存在关系。
3. 当前 90 s 与 180 s 窗口同时改变最大搜索时滞（分别为 30 s、60 s），窗口长度效应与搜索边界效应尚未分离。
4. 180 s 下 Pearson 与 Spearman 的中位时滞差异较大，长窗口结果对相关度量敏感。
5. 当前流量分组结果仍不支持高流量对应更短时滞的单调关系。

# 实验协议

- 数据源由 [SHA-256 清单](../../data/metadata/checksums.sha256)锁定。各炉保留原生波长和独立炉次标识。
- 第一问的人工注入、实测峰遮挡和实际修复各有独立分数。疑似截顶的模板值应随口径注明。
- 第二问的窗口峰位误差以秒计，优化包留炉烟气读数误差以 m³/s 计。各模型在同一口径下共用测试时刻。
- 第三问按炉次外层留一。试验中的标准化、降维、时滞与超参数只由训练炉拟合。实时输入使用发布时可得观测。
- 复算目录由各实验配置控制。正式图表可追溯到 [实验入口](../../experiments/) 和 [历史交付](../../archive/)。

# Q2.3：预白化与多指标时滞识别（探索性归档）

## 数据与协议
使用正式仓库十炉 process_curves CSV，共 13,589 原始时点。H0 按题面 0.5 s/行；H1 仅对附件5时间轴乘2、原10秒居中流量估计除2，因此该炉在 H1 中对应20秒物理平滑窗口。H1 未经设备日志确认，不替代 H0。气体采用原始读数。

在2秒网格上使用90/180秒非重叠窗口；前60/120秒作供氧参照，分别搜索0–30/0–60秒非负滞后，所有候选使用相同长度。分别去线性趋势，由供氧参照估计 AR(1) 系数，施加同一滤波器到两序列。比较绝对 Pearson、绝对 Spearman、双中心距离相关平方（代码及表中简称 dcor）。采用远端循环错位、重复最大峰搜索，按指标、情景、窗宽、气体做 BH 校正。错位负对照仅是诊断，因非平稳和可交换性不保证，不能解释为严格显著性检验；90秒窗口只有13个远端移位，p值分辨率有限。

炉内中心化估计流量斜率，炉次等权。LOHO 比较训练炉均值固定时差与训练炉线性流量模型，目标是窗口互相关/距离相关峰位，不是已知物理时滞真值。未采用独立的同阶段控制。此前十炉已被多轮探索，不能视为外部确认集。

## 已运行结果
上一轮 JavaScript 实验实际计算1284条窗口×指标结果，24组汇总。冻结汇总见 [frozen_summary.csv](../../results/q2/prewhitened_delay/tables/frozen_summary.csv)。

- H0下90秒窗口每气体71个，三个指标的 BH q<=0.1 窗口均为0。
- H0下180秒窗口每气体33个，Pearson CO2有12个窗口达上述诊断阈值；H1下35个窗口中有14个。Spearman及距离相关平方均未复现。
- H0下Pearson中位峰位随窗口从90秒改180秒，CO2从12秒至38秒、CO从12秒至34秒。
- H0的12项LOHO对照中，线性流量模型全部比固定均值基准差；H1个别小幅改善，跨指标及窗宽不稳健。
- 供氧至气体测量的有效时差同时包括炉内反应、输运和仪器响应。不能将这些峰位直接解释为烟道运输时间，亦不能作为第三问光谱时滞真值。

## 归档状态
本次提交冻结已实际获得的24行汇总及 Python 复算入口。逐窗口原始中间结果未持久化，须由入口重算。Python 代码为已执行 JS 方法的移植，尚未独立端到端复跑验证，数值并列峰等可能存在差异。发现原探索代码的低位模运算随机数可能影响炉级 bootstrap，故冻结汇总不包含该区间；复算入口已更换为 NumPy 随机发生器，新的区间待复核。没有生成新图，没有修改2.2、原始数据、既有冻结成绩或第三问模型。

## 决策
保留固定时滞作为简洁比较基准，流量越大时延越小仅作为题面物理先验，尚未被稳健实证确认。不以选择特定窗口、指标或修改时基来强造单调结论。下一轮应检查氧枪阶跃响应、同阶段激励、共同滞后域与负对照，并区分化学响应和输运机制。

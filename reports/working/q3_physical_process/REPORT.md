# 第三问物理过程探索实验报告（十炉）

## 0. 研究对象与边界

官方题目明确：光谱与烟气均按0.5 s采样；光谱2047个波长通道；烟气两列分别为CO₂和CO瞬时体积流量；累计耗氧量为氧枪累计输入氧气体积。第三问要求研究光谱与烟气的实时/延迟互补关系，并用炉口光谱实时预测延迟烟气，且在十炉上验证泛化能力。

本轮使用官方附件1–10原始数据，主分析严格按0.5 s/行。除为计算局部变化而使用5点中值滤波外，不对原始烟气曲线做人工删点。氧枪瞬时流量由累计耗氧量差分估计，并经11点中值滤波；它不是直接观测的流量传感器读数。

本报告是探索性证据，不是因果识别，也不把十炉观察直接等同于普遍冶金定律。

## 1. 十炉是否存在共同冶炼阶段？光谱能否识别？

### 1.1 气体变化的先后顺序

用每炉前30 s烟气中位数作为基线，对CO、CO₂分别进行5点中值滤波；把“连续10个采样点（5 s）超过基线 + 动态范围的10%”定义为该气体的观测启动时刻。

结果：**10/10炉均为CO₂先达到阈值，CO随后达到阈值**。CO₂领先CO的中位时间为77.5 s，范围24.0–172.5 s；精确双侧符号检验 p=0.0020。把阈值改为动态范围的5%、20%、30%，仍然是10/10炉CO₂先于CO，领先时间中位数分别为58.0、128.75、134.5 s。详见 `tables/gas_onset_order_threshold_sensitivity.csv`。

这证明十炉在观测烟气上存在稳定的先后顺序：CO₂先起升，CO后起升。但它不能单独证明某个具体化学反应先后发生，因为两个通道的响应阈值、烟气混合和分析仪动态也会影响起升时刻。

### 1.2 粗粒度三阶段画像

为了比较十炉，将每炉的估计氧枪流量、log(1+CO)、log(1+CO₂)、CO₂占比组成过程特征，稳健标准化后进行三段连续分割。这个三段划分是一个可比较的粗粒度描述，不是预先认定真实冶炼一定只有三阶段。

跨炉方向一致性：

- 第二阶段CO₂均值高于第一阶段：10/10炉。
- 第三阶段CO₂均值低于第二阶段：10/10炉。
- 第三阶段CO均值高于第二阶段：9/10炉；唯一反例为6C02059，其第三段主要落在末端烟气断崖区域。
- 第三阶段CO₂占比低于第二阶段：9/10炉；同样的反例是6C02059。

因此可以提出一个有数据支持的粗粒度物理叙述：**启动阶段烟气整体较弱；随后进入CO₂较强的过渡阶段；再进入CO占比明显提高、CO₂相对下降的阶段。** 这更像是阶段间气体组成的演变，而不是所有炉次都严格遵循固定时长的三段工艺程序。

但常规分段BIC在候选1–6段中，十炉全部选择了上限K=6（`tables/stage_number_BIC.csv`）。由于时间序列强自相关，常规BIC会偏向更多分段；这说明数据中有多次局部变化，不能据此断言真实阶段数就是6，也不能把三段划分当成唯一物理分期。

### 1.3 阶段转换能否从光谱识别？

用光谱32个等宽波段特征（每个波段取log强度均值）进行留一炉交叉验证；另做2047个原始波长通道的全光谱分类。目标阶段标签来自供氧与烟气过程信号的三段分割。

                             model  balanced_accuracy  macro_F1    n
                     spectrum_only           0.513718  0.506020 2721
                time_progress_only           0.812991  0.814945 2721
                spectrum_plus_time           0.742882  0.755553 2721
full_2047_wavelength_spectrum_only           0.525969  0.520082 2721

32波段光谱-only balanced accuracy为0.514，全2047通道为0.526；高于三分类机会水平0.333，但明显低于仅用炉程时间进度的0.813。光谱+时间为0.743，也没有超过时间进度基准。全光谱模型每炉按自身无标签光谱分布做了中心化/尺度归一化，且每5行抽取一帧；它是阶段信息诊断，不是严格实时部署测试。独立光谱分段与过程分段的边界绝对误差中位数：第一边界48.0s，第二边界285.2s。

结论：**光谱含有一定阶段信息，但本轮实验不支持“仅凭当前光谱特征即可稳定识别阶段转换”。** 尤其第二个转折点在多数炉次中没有与光谱独立分段对齐。不能把火焰光谱当成一个已经验证的阶段标签传感器。后续需要研究谱线级特征、特定波段的变化率，以及Q1清洗/重构后的光谱能否提高这一结果。

## 2. CO与CO₂同步、错位还是不同机制？

### 2.1 长周期共同变化

原始log烟气曲线的零滞后相关中位数为0.666，说明两者在整炉尺度上往往随总体冶炼强度共同升降。

### 2.2 去趋势后的局部变化

对log烟气做30 s滚动中值去趋势后，CO与CO₂零滞后相关的中位数为-0.194，十炉均为负值；第一差分相关中位数为0.344。分阶段后，第三阶段CO–CO₂去趋势零滞后相关的跨炉中位数约为-0.579，而第一阶段接近0。

这意味着：长期趋势上二者同涨同落，但扣除共同趋势后，局部波动常呈反向变化；在CO占比更高的后段，这种反向关系更明显。它与CO/CO₂组成重新分配的解释相容，但仅凭相关系数不能证明CO发生了二次氧化。

### 2.3 是否存在统一固定滞后？

在±30 s范围内寻找去趋势互相关绝对峰值，峰值滞后的中位数为0.0s，范围-19.0–25.5s，方向不统一。也就是说，CO与CO₂不是简单的两条固定平移曲线；它们的局部关系随炉次和阶段变化。

第五、七炉的原始一阶差分相关分别高达0.958和0.976，主要受到末端同时断崖影响。将第五炉最后30 s、第七炉最后60 s（覆盖各自疑似断崖区）从敏感性分析中暂时剔除后，差分相关分别降至0.295和0.155；替换这两炉的敏感性值后，十炉差分相关中位数由0.344降至约0.287。主结果仍保留全部数据；该对照说明尾端事件会严重扭曲CO/CO₂动态关系，但不能据此确认是记录器关闭。

## 3. 相同光谱变化在不同工况下是否对应不同烟气响应？

### 3.1 方法

光谱变化分别用全谱平均log(1+强度)的5 s变化量，以及32波段特征PC1的5 s变化量表示。CO、CO₂分别使用log(1+流量)的5 s变化量作为响应，固定考察0、5、10、20、30 s滞后，不从结果中挑选单一最佳滞后。

状态分层：每炉氧枪估计流量低/中/高三分位；累计耗氧进度早/中/晚三分位；以及前述回顾性三段过程阶段。对每种状态，计算0–30 s范围内绝对相关的平均值，再做十炉配对对比。

### 3.2 结果

- **瞬时氧枪流量分层：** CO、CO₂两种响应均未发现稳定显著的高流量—低流量差异；多重检验校正后均不显著。
- **累计耗氧进度分层：** CO的光谱亮度变化—CO变化关联在后段比前段弱，平均绝对相关差约-0.028，95% bootstrap CI [-0.043, -0.015]，Holm校正p=0.047。但这是小效应；换成光谱PC1变化后，Holm校正p=0.172，不再显著。CO₂没有显著的早晚差异。
- **过程阶段分层：** CO在第三阶段的光谱—烟气关联较第一阶段偏弱，但原始p值约0.07–0.08，多重检验校正后不显著；CO₂没有稳定差异。

结论：**目前只有较弱证据表明累计耗氧进度会改变光谱变化与CO响应之间的关联；没有足够证据证明瞬时流量或阶段本身会稳定改变CO₂响应。** 这不支持强交互模型已经成立，但提示CO的映射关系可能随冶炼进度变化。

重要限制：阶段标签是用供氧和烟气共同构造的，因此按阶段比较属于回顾性条件关联，不是可直接部署的实时阶段输入，也不是因果效应。

## 4. 第五炉1 s敏感性

官方主口径仍为0.5 s/行。第五炉若改为1 s，记录时长由387 s变为774 s，平均估计氧枪流量由约9.14降至4.57 m³/s；按秒计的阶段边界和滞后也相应翻倍，但以采样行数衡量的曲线顺序与相关结构不变。详见 `tables/heat5_timebase_sensitivity.csv`。这不能证明1 s是真实采样间隔。

## 5. 对第三问建模的直接含义

1. CO和CO₂必须分开建模：它们的启动时刻、后段变化方向和局部相关结构不同。
2. 不宜把一个固定时滞用于所有炉次、所有阶段；本轮CO–CO₂互相关峰滞后方向和位置都不稳定。光谱到烟气的滞后仍需另行估计，不能用CO–CO₂滞后替代。
3. 单一全谱亮度不足以代表光谱；应保留谱线/波段形状特征，尤其需要使用Q1重构后的光谱复核。
4. 累计耗氧进度对CO映射可能有弱调节作用；目前不支持把氧枪瞬时流量作为强交互项的确定证据。
5. 第五、七炉末端突降必须保留原始版本并做标记敏感性分析，不可仅因它们降低拟合度就删除。

# 第三问实验｜异质性曲线、实时光谱与跨炉方差

更正后的十炉、13,589 帧光谱均已与原工作簿核对。以炉为单位留一验证，每次只用另外九炉训练，预测未来检测器的 CO₂、CO 瞬时流量。主情景每个模型、每种气体各有 11,189 个测试时点。三个情景、七种模型、两种气体合计 420 个逐炉评分和 471,618 条逐点预测；由预测表独立复核了 R²、残差方差及其跨炉汇总。

## 文献和方法选择

- Ramsay 与 Li 将曲线差异分为横向的时间或阶段错位，以及纵向的响应幅度差异。本实验沿用仓库 V5 的可实时计算的供氧进度，以便不同炉次在近似相同的反应进度下相比较。使用可观测进度可避免为了对齐而偷看测试炉的未来烟气。[Curve Registration，1998](https://www.ece.uvic.ca/~bctill/papers/mocap/Ramsay_Li_1998.pdf)
- Yao、Müller、Wang 利用函数主成分刻画不同个体的曲线，并在其稀疏纵向观测条件下估计个体得分。Scheipl、Staicu、Greven 以函数型随机效应表示个体偏离总体的方式。本实验借鉴共享曲线加个体偏差的结构，测试炉得分只由前 60 秒的外生特征估计；未实现 PACE 条件估计或完整的混合效应推断。[Yao 等，2005](https://doi.org/10.1198/016214504000001745) · [Scheipl 等，2015](https://doi.org/10.1080/10618600.2014.901914)
- Gao 等研究了转炉炉口光谱与延迟烟气，使用神经网络预测累计流量。本实验预测未平滑的瞬时流量，以相同提前量和测试时间做光谱消融。[Gao 等，2024 年在线发表](https://doi.org/10.1177/03019233241273473)

## 实验设计

以 \(t\) 为发布时刻，检测器目标为 \(G(t+d)\)。主情景 H0 按 0.5 秒/行，对每个外层折和气体，沿用 V5 的第二问固定时滞选择规则，在九炉内再留一炉，按 MAE 从 6、12、…、60 秒选择 \(d\)。CO₂ 实际取 24–60 秒，CO 取 12–60 秒。所有模型对同一折使用相同的 \(d\) 与原始目标，仅评价检测时刻 ≥120 秒。另做 H0 下统一 30 秒、H1 下统一 30 秒对照。H1 仅假设附件 5 每行 1 秒。这些提前量没有独立的输运时间真值。

净耗氧记为 \(O(t)\)。在评分对应的发布序列上计算 \(u(t)=\max_{s\le t}\{O(s)+1.25d\,O(s)/s\}\)，由历史平均供氧外推短时进度。九炉训练曲线映射到 10 m³ 的耗氧网格，以标准差 60 m³ 做高斯平滑，再按实际覆盖平均。没有训练炉覆盖的端部使用端值延拓。新炉不使用终点耗氧、未来光谱、当前或历史烟气。

1. **共享曲线**直接预测 \(\mu(u)\)。保留为所有方法的基准。
2. **整炉形状预测**用前两个函数主成分拟合训练炉偏差。用前 60 秒的过程统计量，或再加上初始光谱统计量，岭回归预测两项得分，岭参数固定为 10。缺失支持区的偏差置零。
3. **局部误差预测**分别拟合极端随机树和双隐藏层神经网络。每个训练炉先用其余八炉建立模板，以自身观测减去该模板为训练目标。新炉采用 \(\widehat G=\max(0,\mu(u)+0.5\widehat r)\)。每种算法均比较纯过程与光谱＋过程。过程变量包括当前耗氧、进度、时间及 10/30/60 秒后向流量；16 个物理波段覆盖 345–1015 nm，提取对数亮度、上尾对比度、5 秒单边平均、与 30 秒均值之差及相对初始值。测试炉最早发布时刻为 60 秒。
4. 树模型用 96 棵树、每叶至少 20 个样本、候选特征比例 0.65。神经网络采用 16、8 个隐藏单元、tanh、全批量 Adam、60 次更新。训练残差每 2 秒取样，各炉总权重相等；预测覆盖所有原始测试行。随机种子 20261127。除提前量外的上述超参数固定。对比过同一批炉次后提出的模型推荐属于探索性结果。

## 主情景的均值和方差

每炉先求 \(R_h^2\) 以及残差 \(e_{hi}=\hat y_{hi}-y_{hi}\)。下表“炉间方差”是十个 \(R_h^2\) 的样本方差，分母为 9；“残差方差”是各炉内部残差样本方差的等权平均，单位为 (m³/s)²。分数越集中，炉间方差越小。残差方差剔除了每炉平均偏差，须同时看 MAE 或 RMSE。表内每组数据按 CO₂ / CO 排列。

| 模型 | 平均 R² | R² 炉间方差 | 平均炉内残差方差 |
|---|---|---|---|
| 共享耗氧进度曲线 | 0.4719 / 0.7155 | 0.1094 / 0.0523 | 4.340 / 39.884 |
| 初段过程 → 函数主成分得分 | 0.3991 / 0.6731 | 0.2671 / 0.1081 | 4.557 / 43.474 |
| 初段过程＋光谱 → 函数主成分得分 | 0.2907 / 0.6118 | 0.5631 / 0.2519 | 5.447 / 50.299 |
| 过程残差树 | 0.4427 / 0.7086 | 0.1053 / 0.0488 | 4.771 / 43.444 |
| 融合残差树 | 0.4862 / 0.7209 | 0.0937 / 0.0428 | 4.631 / 38.693 |
| 过程神经网络 | 0.4176 / 0.7132 | 0.1650 / 0.0460 | 4.654 / 39.730 |
| 融合神经网络 | 0.4930 / 0.7168 | 0.0714 / 0.0428 | 4.667 / 38.315 |

融合树的炉均 MAE 为 1.791 / 5.339 m³/s，RMSE 为 2.376 / 6.933 m³/s。共享曲线的 MAE 为 1.817 / 5.307，RMSE 为 2.390 / 6.917。因此 CO 选择融合树的依据是宏平均 R² 与炉间稳定性；若目标是尽量降低绝对误差，共享曲线仍然有竞争力。融合树相对纯过程树分别有 6/10、7/10 炉的 R² 提高。相对共享曲线则分别是 4/10、7/10 炉提高。

## 敏感性与解释

| 配置 | 共享曲线平均 R² | 融合树平均 R² | 融合网络平均 R² |
|---|---|---|---|
| H0，各训练折选择提前量 | 0.472 / 0.715 | 0.486 / 0.721 | 0.493 / 0.717 |
| H0，统一提前 30 秒 | 0.457 / 0.725 | 0.480 / 0.729 | 0.448 / 0.720 |
| H1，统一提前 30 秒 | 0.504 / 0.757 | 0.507 / 0.762 | 0.480 / 0.768 |

融合树在三个情景下两种气体的平均 R² 均高于共享曲线，幅度有限。CO₂ 网络在主情景下最高，但改为统一 30 秒后低于共享曲线。用初期光谱硬性预测整炉形状的做法在主情景下提高了两种气体的炉间方差，这提示九个训练炉不足以支撑当前初始特征与曲线形状之间的稳定映射。该发现只适用于本实现和这批炉次。

主情景下融合树在第五炉 CO₂ / CO 的 R² 为 0.035 / 0.326，第九炉 CO₂ 为 −0.006。主情景 CO₂ 没有炉次超过 0.9，CO 有两炉超过。保留全部十炉。仓库 V5 的同类无反馈融合汇总为 0.4633 / 0.6776，根据五位小数逐炉表计算的炉间方差为 0.3740 / 0.0885。两轮沿用相同的 H0、评分起点和提前量选择逻辑；V5 是已归档结果，本轮真正隔离光谱增益的对照是本轮自己的纯过程模型。十折的训练集彼此重叠；所列方差刻画这十炉的离散程度，无法直接推得新炉的置信区间。[V5 逐炉表](https://github.com/zhoushuming073-cell/B-APMCM/blob/526387f/results/q3/v5_causal_spectral/fold_r2_rounded.csv)

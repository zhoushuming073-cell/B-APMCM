## Restore and reproduce

From the repository root (Python 3.13; original environment recorded in environment.txt):

```bash
git lfs pull
python experiments/q2_final_validation/restore_package.py --out q23_reproduction
python -m pip install -r q23_reproduction/requirements.txt
python q23_reproduction/run_q23_final_validation.py --data-zip data/raw/official/Data.zip --out q23_final_output --simulations 100 --seed 20261128
```

Both output directories must be empty or absent. The first command restores the original 26-file source/input package and validates every member and the complete archive SHA-256. Its ten binary parts are stored in normal Git; no separate attachment is needed. The official Data.zip remains managed through the repository's existing Git LFS convention. The source archive reuses the frozen Q2.1 flow profile rather than rerunning its costly model selection.
